## 🚀 How to Deploy

### Option 1 — Netlify Drop (Fastest)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag and drop `portfolio.html`
3. Get a live URL instantly — no account needed

### Option 2 — GitHub Pages
1. Create a new GitHub repository
2. Upload `portfolio.html` and rename it to `index.html`
3. Go to **Settings → Pages → Branch: main → Save**
4. Your site will be live at `https://<username>.github.io/<repo-name>`

### Option 3 — Vercel
1. Go to [vercel.com](https://vercel.com) and sign in
2. Click **Add New → Project** and upload the file
3. Deploy — get a URL like `https://portfolio.vercel.app`
